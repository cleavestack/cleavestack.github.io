# cleavestack.com

Marketing site for Cleavestack, the commercial home of [MMCA](https://github.com/ivanball/MMCA.Common),
the open-source modular monolith framework for .NET.

Static site, no build step. Published via GitHub Pages with the custom domain `cleavestack.com`
(see `CNAME`). Fonts are self-hosted in `assets/fonts/` (Inter Variable + JetBrains Mono, latin
subsets); the site makes no third-party requests.

Brand source of truth: the Cleavestack brand book (positioning, messaging, verbal and visual
identity) in the private workspace at `Docs/Planning/Cleavestack-Brand.md`.
